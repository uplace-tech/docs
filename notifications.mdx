## Objectif

Maîtriser ce que vous recevez d'Uplace : quels événements déclenchent une alerte, sur quel périmètre de lots, et par quel canal.

<Note>
  Ne confondez pas les deux familles de communications :

  - les **notifications**, qui vous sont adressées à vous, membre de l'agence — c'est l'objet de cette page ;
  - les **messages envoyés aux tierces parties** (candidats, garants, propriétaires, GLI), qui partent automatiquement au nom de l'agence — voir [Messages envoyés aux candidats](/messages-candidats).
</Note>

## Les trois canaux

| Canal | Description |
| --- | --- |
| **E-mail** | Envoyé à l'adresse de votre compte. C'est le canal utilisé par toutes les notifications. |
| **In-app** | Affiché dans **Mes notifications**, dans l'application. |
| **SMS** | Réservé à un usage très ciblé : côté agence, seul le rappel de visite à H-2 l'utilise. |

## Régler ses préférences

Les préférences de notification sont **personnelles**. Chaque membre de l'agence règle les siennes, sans impact sur ses collègues.

<Steps>
  <Step title="Ouvrir le panneau Mes notifications">
    Le panneau **Mes notifications** regroupe l'ensemble de vos réglages, organisés en quatre sections : Général, Lots, Visite, et Chat et discussion.
  </Step>
  <Step title="Choisir le périmètre pour les événements liés aux lots">
    Trois événements se règlent par périmètre plutôt que par simple interrupteur. Pour chacun, vous choisissez entre :

    - **Sur un bien de l'agence** — vous êtes alerté pour tous les lots, y compris ceux de vos collègues ;
    - **Sur les biens dont je suis le gestionnaire** — vous n'êtes alerté que sur votre propre portefeuille ;
    - **Aucune notification**.

    Ce réglage existe pour : _Un candidat prend contact via une plateforme d'annonce_, _Un dossier complet est déposé et analysé_, et _Un candidat réserve un créneau de visite_.
  </Step>
  <Step title="Activer les rappels de visite">
    Deux interrupteurs indépendants : **rappel la veille** de votre visite, et **rappel deux heures avant**.
  </Step>
  <Step title="Activer le rapport quotidien">
    Dans la section **Général**, l'interrupteur **Rapport journalier** vous envoie un récapitulatif quotidien de vos lots.
  </Step>
  <Step title="Ajuster pour un lot en particulier">
    Les réglages ci-dessus valent pour l'ensemble de votre périmètre. Pour couper ou rétablir les notifications sur **un seul lot**, rendez-vous sur le [Dashboard](/dashboard) et utilisez le **bouton actions** de la ligne du lot concerné.

    Là encore, le réglage est personnel : couper les notifications d'un lot ne les coupe pas pour vos collègues.
  </Step>
</Steps>

## Les réglages disponibles

### Général

| Réglage | Type |
| --- | --- |
| Rapport journalier — un récapitulatif quotidien de vos lots | Interrupteur |

### Lots

| Événement | Type |
| --- | --- |
| Un candidat prend contact via une plateforme d'annonce | Agence / Mes lots / Aucune |
| Un dossier complet est déposé et analysé | Agence / Mes lots / Aucune |

### Visite

| Événement | Type |
| --- | --- |
| Un candidat réserve un créneau de visite | Agence / Mes lots / Aucune |
| Recevoir un rappel la veille de ma visite | Interrupteur |
| Recevoir un rappel deux heures avant ma visite | Interrupteur |

### Chat et discussion

| Événement | Type |
| --- | --- |
| Vous êtes mentionné dans une discussion interne | Interrupteur |
| Un candidat vous envoie un message | Interrupteur |

## Bonnes pratiques recommandées

<Tip>
  - Réglez le périmètre sur **Sur les biens dont je suis le gestionnaire** plutôt que sur toute l'agence : c'est le meilleur compromis entre réactivité et volume d'e-mails.
  - Gardez **Prise de contact** activé : c'est l'événement qui conditionne votre délai de réponse, et donc votre référencement sur les portails.
  - Activez le **rapport journalier** si vous coupez beaucoup de notifications unitaires : vous gardez une vision d'ensemble sans subir le flux.
  - Utilisez la coupure **par lot** depuis le Dashboard pour les biens très exposés qui génèrent un volume anormal de contacts, plutôt que de tout couper globalement.
</Tip>

## Erreurs fréquentes à éviter

<Warning>
  - Couper **Un dossier complet est déposé et analysé** puis s'étonner de découvrir des dossiers complets plusieurs jours après leur dépôt.
  - Croire que couper les notifications d'un lot les coupe pour toute l'équipe : le réglage est **personnel**.
  - Attendre un SMS pour une notification autre que le rappel de visite à H-2.
  - Laisser le périmètre sur **Sur un bien de l'agence** dans une agence à fort volume : le bruit finit par masquer les événements qui vous concernent.
</Warning>

## Questions fréquentes

<AccordionGroup>
  <Accordion title="Si je coupe les notifications d'un lot, mes collègues les reçoivent-ils encore ?">
    Oui. Toutes les préférences de notification sont personnelles, y compris la coupure lot par lot depuis le Dashboard.
  </Accordion>

  <Accordion title="Puis-je choisir de recevoir certaines notifications uniquement dans l'application, sans e-mail ?">
    Le réglage porte sur l'événement et son périmètre, pas sur le canal. Les notifications qui existent en in-app sont également envoyées par e-mail.
  </Accordion>

  <Accordion title="Pourquoi ne reçois-je aucune alerte sur les lots de mes collègues ?">
    Parce que le périmètre est probablement réglé sur **Sur les biens dont je suis le gestionnaire**. Basculez-le sur **Sur un bien de l'agence** pour élargir. Attention : si vous avez le rôle Utilisateur ou Opérateur, votre visibilité reste de toute façon limitée à vos propres lots — voir [Rôles et permissions](/roles-permissions).
  </Accordion>

  <Accordion title="Qu'est-ce qu'une mention dans une discussion interne ?">
    Les membres de l'agence peuvent échanger entre eux dans une discussion interne et s'y mentionner. Vous êtes alors notifié, par e-mail et dans l'application.
  </Accordion>

  <Accordion title="Le rappel de visite est-il aussi envoyé au candidat ?">
    Oui, le candidat reçoit ses propres rappels à J-1 et H-2, indépendamment des vôtres — voir [Messages envoyés aux candidats](/messages-candidats).
  </Accordion>
</AccordionGroup>
