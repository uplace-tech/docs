## À qui s'adresse ce guide

Une agence immobilière vous a confié les visites d'un ou plusieurs biens et vous a envoyé une invitation par e-mail. Ce guide explique comment accéder à votre espace et vous en servir.

<Note>
  **Vous n'avez pas de compte à créer et pas de mot de passe à retenir.** Votre accès repose sur votre adresse e-mail et un code reçu à chaque connexion.
</Note>

## Les deux e-mails que vous pouvez recevoir

<AccordionGroup>
  <Accordion title="« Invitation à gérer les visites d'un bien »">
    L'agence vous confie un bien et vous demande d'**organiser vous-même les visites**.

    L'e-mail présente le bien — photo, référence, intitulé, surface, loyer mensuel et commune — puis un bouton **Accéder à la gestion des visites**.

    <Warning>
      **Conservez cet e-mail.** Il contient votre lien d'accès unique à la gestion des visites.
    </Warning>
  </Accordion>

  <Accordion title="« Une visite vous a été confiée »">
    L'agence a déjà calé le rendez-vous et vous demande simplement de l'assurer. L'e-mail précise la **date et le créneau horaire** — par exemple _le 18/08/2026 de 14:00 à 14:30_ — ainsi que le bien concerné, puis un bouton **Voir mes visites**.
  </Accordion>
</AccordionGroup>

Ces deux e-mails correspondent aux deux façons dont une agence peut travailler avec vous : soit elle vous laisse créer vos créneaux, soit elle vous assigne des visites qu'elle a planifiées.

## Se connecter à son espace

Votre espace se trouve sur [**app.uplace.fr/subcontractor**](https://app.uplace.fr/subcontractor).

<Steps>
  <Step title="Saisir votre adresse e-mail">
    Sur l'écran **Accéder à mes visites**, indiquez l'adresse e-mail **sur laquelle vous recevez les invitations de visite**. C'est la seule qui fonctionne.
  </Step>
  <Step title="Recevoir votre code">
    Cliquez sur **Recevoir mon code**. Uplace vous envoie un code unique par e-mail.
  </Step>
  <Step title="Saisir le code">
    Entrez le code reçu pour ouvrir votre espace.
  </Step>
</Steps>

<Note>
  Cette vérification par e-mail remplace le mot de passe : elle garantit que seule la personne qui reçoit les invitations peut consulter les visites et les coordonnées des candidats.
</Note>

## Votre espace « Mes visites »

Une fois connecté, vous voyez l'ensemble de vos visites et des biens qui vous ont été confiés, **regroupés par jour**.

Chaque visite s'affiche sous forme de carte :

| Élément | Ce que c'est |
| --- | --- |
| **Le bien** | Photo, intitulé du logement et **nom de l'agence** qui vous l'a confié. |
| **Le compteur** | Le remplissage du créneau, sous la forme _inscrits / places_ — par exemple `0 / 1`. |
| **L'horaire** | L'heure de début et de fin du créneau. |
| **L'adresse** | Le **lieu de rendez-vous**, qui n'est pas toujours celui du bien : vérifiez-le avant de partir. |
| **Voir les candidats** | La liste des personnes inscrites sur ce créneau. |
| **L'icône corbeille** | Supprimer le créneau. |

Le bouton **Déconnexion**, en haut à droite, ferme votre session.

### Créer un créneau de visite

Si l'agence vous a confié l'organisation des visites, le bouton **Planifier un nouveau créneau de visite** vous permet d'ouvrir vous-même une plage horaire. Les candidats réservent ensuite leur horaire dessus.

Si l'agence préfère garder la main sur le planning, vous n'avez rien à créer : les visites qu'elle vous assigne apparaissent directement dans votre espace.

## Bonnes pratiques recommandées

<Tip>
  - **Ne supprimez pas les e-mails d'invitation** : ils contiennent votre lien d'accès.
  - Vérifiez le **lieu de rendez-vous** sur la carte de la visite : il peut différer de l'adresse du bien, par exemple si les clés sont à l'agence.
  - Consultez **Voir les candidats** avant de partir : vous saurez combien de personnes vous attendent et qui elles sont.
  - Si vous ne pouvez pas assurer une visite, prévenez l'agence : c'est elle qui gère la réaffectation.
  - Connectez-vous depuis l'adresse e-mail sur laquelle vous recevez les invitations, sans quoi aucun code ne vous parviendra.
</Tip>

## Questions fréquentes

<AccordionGroup>
  <Accordion title="Dois-je créer un compte Uplace ?">
    Non. Vous n'avez ni compte ni mot de passe. Vous saisissez votre adresse e-mail, vous recevez un code, et vous accédez à votre espace.
  </Accordion>

  <Accordion title="Je ne reçois pas mon code, que faire ?">
    Vérifiez que vous utilisez bien l'**adresse e-mail sur laquelle l'agence vous envoie les invitations de visite** — c'est la seule reconnue. Pensez aussi à regarder dans vos courriers indésirables.
  </Accordion>

  <Accordion title="J'ai perdu l'e-mail d'invitation.">
    Vous pouvez toujours passer par [app.uplace.fr/subcontractor](https://app.uplace.fr/subcontractor) et demander un code. Si votre espace reste vide, contactez l'agence : c'est elle qui vous rattache aux biens.
  </Accordion>

  <Accordion title="Puis-je créer mes propres créneaux de visite ?">
    Cela dépend de ce que l'agence a choisi. Si elle vous a confié l'organisation, le bouton **Planifier un nouveau créneau de visite** est disponible. Sinon, elle crée les visites et vous les assigne.
  </Accordion>

  <Accordion title="Que vois-je exactement des candidats ?">
    Les personnes inscrites sur les créneaux que vous assurez, via **Voir les candidats**. Vous n'avez pas accès au reste de l'activité de l'agence ni aux dossiers locatifs.
  </Accordion>

  <Accordion title="Puis-je travailler pour plusieurs agences ?">
    Oui. Votre espace regroupe toutes les visites qui vous sont confiées, et chaque carte indique le **nom de l'agence** concernée.
  </Accordion>

  <Accordion title="Comment annuler un créneau ?">
    L'icône corbeille sur la carte de la visite permet de supprimer le créneau. Prévenez l'agence : elle doit savoir que le bien n'est plus couvert.
  </Accordion>
</AccordionGroup>
