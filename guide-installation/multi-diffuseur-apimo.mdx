## Connecter Apimo

<Steps>
  <Step title="Faire la demande de connexion depuis Uplace">
    [Mon agence](/mon-agence) > **Paramètres de l'agence** > **Multi-diffuseurs** > **Demande d'activation**.
  </Step>
  <Step title="Renseigner votre ID Apimo">
    Indiquez votre **ID Apimo** dans le champ prévu, puis validez.

    <Frame>
      ![04 Apimo Uplace Id Agence](/images/04-apimo-uplace-id-agence.png "04 Apimo Uplace Id Agence")
    </Frame>
  </Step>
</Steps>

<Note>
  La validation reste à la main de l'éditeur : la connexion n'est donc pas active immédiatement. Une fois établie, vos annonces remontent dans [Lots en attente](/lots-en-attente).
</Note>

## Erreurs fréquentes à éviter

<Warning>
  - Activer l'interrupteur _La connexion est établie_ avant la validation effective côté Apimo.
  - Renseigner un ID agence erroné : la demande d'activation restera sans effet.
</Warning>

## Questions fréquentes

<AccordionGroup>
  <Accordion title="Où trouver mon ID agence Apimo ?">
    Il figure dans votre espace Apimo. En cas de doute, le support Apimo vous le communique : [support@apimo.com](mailto:support@apimo.com) — 04 92 91 90 63.
  </Accordion>

  <Accordion title="Combien de temps prend l'activation ?">
    Elle dépend du traitement côté Apimo. Tant qu'elle n'est pas effective, laissez l'interrupteur de connexion inactif dans Uplace et créez vos lots par **import d'URL** ou en **saisie manuelle**, voir la [vue d'ensemble](/guide-installation/annonces).
  </Accordion>
</AccordionGroup>
