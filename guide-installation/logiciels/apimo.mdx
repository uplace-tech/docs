<Note>
  Cette page couvre les **deux volets** de l'installation pour Apimo. Les principes généraux sont sur [Remontée et création d'une annonce](/guide-installation/annonces) et [Rediriger les prises de contact](/guide-installation/prises-de-contact).
</Note>

<Check>
  **Connexion native.** Une API est en place : une fois l'activation validée, Uplace récupère directement les données de vos annonces.
</Check>

<Steps>
  <Step title="Faire la demande de connexion depuis Uplace">
    [Mon agence](/mon-agence) > **Paramètres de l'agence** > **Multi-diffuseurs** > **Demande d'activation**.
  </Step>
  <Step title="Renseigner votre ID Apimo">
    Indiquez votre **ID Apimo** dans le champ prévu, puis validez.

    <Frame>
      ![04 Apimo Uplace Id Agence](/images/04-apimo-uplace-id-agence.png "04 Apimo Uplace Id Agence")
    </Frame>
  </Step>
</Steps>

<Warning>
  Un ID agence erroné laisse la demande sans effet. Et n'activez pas l'interrupteur _La connexion est établie_ avant la validation effective côté Apimo.
</Warning>

<Note>
  Une fois la connexion active, vos annonces remontent dans [Lots en attente](/lots-en-attente), prêtes à être rapprochées. Les étapes 1 à 3 de la [création d'un lot](/creation-lot) arrivent pré-remplies.
</Note>

<Note>
  Munissez-vous de votre **e-mail automatique** `nom-de-votre-agence@inbox.uplace.fr` : voir [Rediriger les prises de contact](/guide-installation/prises-de-contact).
</Note>

Le principe est le même que pour les autres logiciels : remplacer l'adresse e-mail de contact **location** par votre e-mail automatique. La marche à suivre précise dans Apimo n'est pas encore documentée ici — écrivez à [contact@uplace.fr](mailto:contact@uplace.fr) et l'équipe la fait avec vous.

<Warning>
  Pour **Leboncoin**, la modification ne se fait pas en libre-service quand vous êtes sur Apimo : elle passe par votre conseiller clientèle Leboncoin — voir [Leboncoin](/guide-installation/plateformes/leboncoin).
</Warning>

## Questions fréquentes

<AccordionGroup>
  <Accordion title="Où trouver mon ID agence Apimo ?">
    Il figure dans votre espace Apimo. En cas de doute, le support Apimo vous le communique : [support@apimo.com](mailto:support@apimo.com) — 04 92 91 90 63.
  </Accordion>

  <Accordion title="Combien de temps prend l'activation ?">
    Elle dépend du traitement côté Apimo. Tant qu'elle n'est pas effective, laissez l'interrupteur de connexion inactif dans Uplace et créez vos lots par **import d'URL** ou en **saisie manuelle**, voir [Création d'un lot](/creation-lot).
  </Accordion>
</AccordionGroup>
